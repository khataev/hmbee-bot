## Канбан-доска задач (Planka)

Доска задач проекта — Planka, доступна через MCP-сервер `planka-mcp` (аутентификация по API-ключу). Проект **Прочие**, доска **Honey Money Bot**, списки: «К выполнению», «В работе», «Тест», «К деплою», «Постдеплой», «Завершена».

Если пользователь просит создать задачу (в чате или в описании/комментарии PR на GitHub):

1. Название задачи — с префиксом `[HMB-XXX]`, где `XXX` — следующий порядковый номер.
2. Номер берётся из карточки-счётчика: в списке «К выполнению» есть карточка с меткой **СЧЕТЧИК**, в названии которой хранится последний использованный номер. Взять число из неё, прибавить 1 — это номер новой задачи.
3. После создания задачи обновить название карточки-счётчика на новое число, чтобы он снова указывал на последний использованный номер.
4. Новую карточку создавать в списке «К выполнению» и добавлять себя (агента) в участники карточки через `cardMembers` (action `add`).
