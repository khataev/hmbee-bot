# Правила работы с OpenSpec

- При выполнении apply (`/opsx:apply` и аналоги) — перед началом работы спросить человека, как выполнять задачи: все за один проход, или по группам (секции `## N. ...` в `tasks.md`) с остановкой после каждой группы для ревью.
  - Если выбран режим по группам — после завершения всех задач одной группы остановиться, кратко резюмировать изменения и дождаться подтверждения человека перед тем, как переходить к следующей группе.
