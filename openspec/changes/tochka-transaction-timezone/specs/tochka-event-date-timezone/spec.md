## ADDED Requirements

### Requirement: Нормализация даты транзакции Точки по глобально настроенному часовому поясу
Система SHALL приводить значение `meta_data.time_data.event_date` к часовому поясу из корневого поля `time_zone` конфигурации и извлекать из результата только часть `YYYY-MM-DD` как дату транзакции.

#### Scenario: Транзакция после полуночи по UTC+5, но до полуночи по Москве получает московскую дату
- **WHEN** запись Точки содержит `event_date` со временем между 00:00 и 02:59 по UTC+5 (т.е. накануне до 00:00 по UTC+3)
- **AND** в конфигурации задан `time_zone: "Europe/Moscow"`
- **THEN** нормализованная запись имеет `date` равную дате предыдущего дня (по Москве)
- **AND** дата соответствует формату `YYYY-MM-DD`

#### Scenario: Транзакция в дневное время не меняет дату при конвертации
- **WHEN** запись Точки содержит `event_date` со временем между 03:00 и 23:59 по UTC+5
- **AND** в конфигурации задан `time_zone: "Europe/Moscow"`
- **THEN** нормализованная запись имеет `date` идентичную дате, содержащейся в исходном `event_date`

#### Scenario: Настроенный часовой пояс применяется ко всем записям Точки
- **WHEN** в `config/sources.json` задан `"time_zone": "Europe/Moscow"` на корневом уровне
- **AND** запись Точки нормализуется
- **THEN** дата транзакции в нормализованной записи соответствует дате в часовом поясе `Europe/Moscow`
- **AND** формат значения — `YYYY-MM-DD`
