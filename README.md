# HMBee Bot

CLI-утилита на TypeScript для синхронизации финансовых операций из различных источников в сервис [Honey Money](https://honeymoney.me/).

## 🎯 Цель проекта
Автоматизировать (или упростить ручной) импорт данных из банков, которые не имеют прямой интеграции с Honey Money, при соблюдении принципов безопасности и прозрачности для пользователя.

## 🚀 Текущий статус: MVP (Этап 1)
На данном этапе реализован базовый CLI-скелет и поддержка синхронизации из дебет-карты **Точка Банка** через использование данных текущей браузерной сессии.

### Основные возможности:
- **`list`**: Просмотр доступных источников данных.
- **`sync <source>`**: Загрузка транзакций за указанный период с сохранением результата в `sync/<source>/<from>_<to>.json`.
- **`apply <source> --preview`**: Предпросмотр полного draft-представления транзакции для Honey Money.
- **`apply <source>`**: Отправка идентифицированных доходов и расходов в Honey Money c возвратом созданных идентификаторов транзакций.
- **`apply <source> --only-id ...`**: Отправка только выбранных идентифицированных транзакций по списку source id.
- Поддержка экспорта в `raw` (исходный JSON от банка) или `adapted` (нормализованный вид) форматы.
- Вывод результата в консоль или сохранение в файл.

## 🛠 Установка и настройка

1. **Клонирование и зависимости**:
   ```bash
   npm install
   ```

2. **Настройка окружения**:
   Создайте файл `.env` на основе примера. Для работы с Точкой нужны `TOCHKA_COOKIE` и `TOCHKA_CUSTOMER_ID`. Для записи в Honey Money заполните `HM_USER_EMAIL`, `HM_USER_TOKEN` и `HM_COOKIE`; остальные HM-параметры берутся из `.env.example` и при необходимости могут быть переопределены.

3. **Конфигурация**
   Скопируйте файл конфигурации и замените идентификаторы счетов Honey Money на реальные:
   ```bash
   cp config/sources.example.json config/sources.json
   ```


## 📖 Использование

### Список источников
```bash
npx tsx src/index.ts list
```

### Синхронизация данных
Пример получения данных из Точки за январь 2024:
```bash
npx tsx src/index.ts sync tochka --from 2024-01-01 --to 2024-01-31
```

По умолчанию результат будет сохранен в `sync/tochka/2024-01-01_2024-01-31.json`. Если нужен вывод в stdout, используйте `--stdout`.

### Предпросмотр нормализованных данных
Команда `apply --preview` позволяет проверить, как транзакции будут выглядеть после нормализации и маппинга категорий:
```bash
npx tsx src/index.ts apply tochka --preview
```

### Отправка в Honey Money
Команда `apply` отправляет идентифицированные записи в Honey Money и печатает пары source/Honey Money id в JSON:
```bash
npx tsx src/index.ts apply tochka
```

### Отправка только выбранных транзакций

```bash
npx tsx src/index.ts apply tochka --only-id 4223584703,4223565341
```

Если указан `--only-id`, команда все равно работает только с уже идентифицированными записями, а затем дополнительно ограничивает отправку переданным списком source transaction id.
